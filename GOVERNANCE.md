# Governance

Replofy OS is presently maintainer-led.

Maintainers review contributions, manage releases, enforce community policies,
and make final decisions when consensus cannot be reached. Decisions should
favor user safety, self-hosting portability, compatibility of documented public
interfaces, and long-term maintainability.

Substantial changes should begin with a public issue or design proposal covering
the problem, alternatives, compatibility impact, security implications, and
test strategy. Routine fixes may proceed directly through a pull request.

The active maintainers are the repository members with merge permission.
Governance will be revised before 1.0 to document maintainer nomination,
removal, voting, and conflict-resolution procedures as the contributor group
grows.
